# nidar-web.github.io

Static project page for **NIDAR**: NIR-Guided Intrinsic Decomposition for Scalable Scene-Agnostic LiDAR Intensity Reconstruction  .
Project website is [https://nidar-web.github.io/](https://nidar-web.github.io/).

Core Contributor: Junjie Zhang, Jie Yin

## Local Checks

Run `npm test` to check comparison controls and on-demand video playback.
These tests use Node.js built-ins and need no package installation.
